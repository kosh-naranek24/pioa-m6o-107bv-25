В папке pioa-m6o-107bv-25 содержится папку src\\db с папкой backend, которая реализует работу с базой данных студентов (memory.py), а также database.py, file.py, table.py для реализации базы данных, способной "запоминать" полученные данные. Также src\\db содержит \_\_init\_\_.py(для инициализации пространства имён), \_\_main\_\_.py (реализует функции, выполнения модуля или пакета как скрипта), tui.py (для работы с пользовательским интерфейсом). Папка src содержит папку tests, где есть \_\_init\_\_.py, test\_memory.py, test\_file\_database.py, test\_table.py для тестов аналогичных файлов.

Функция реализует базу данных студентов: можно добавлять студентов с их id, именем, фамилией, возрастом, полом. При добавлении данные сохраняются, и после их можно искать по фильтрам любого из параметров. Можно обновлять записи: сначала нужно найти их по фильтру, а потом обновить (необязательно все данные). Функция удаления позволяет удалять записи после поиска подходящих, возвращает список удалённых записей. test\_memory.py содержит тесты для функций создания записей, их поиска по фильтру, обновления, удаления. Итоговое покрытие тестами - 88%.
